# Techcend Web

This repository is split into a Vite React client and a Node/Express server.

## Structure

- `client/` - React frontend built with Vite and Tailwind CSS.
- `server/` - Express API server for chatbot endpoints and backend logic.

## Commands

From the project root:

```bash
npm run dev:client
npm run dev:server
npm run build
npm run lint
```

The server environment file lives at `server/.env` and is ignored by Git.
